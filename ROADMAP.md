# Akmena V2 Roadmap

## Phase A — Core Completion
*   **Sprint 7 — Governance:** Give the protocol the ability to safely evolve. (Strictly scoped: proposals, timelocks, execution, protocol parameter updates).
*   **Sprint 8 — AI Runtime:** Orchestrate the canonical lifecycle (Identity -> Capability -> Discovery -> Agreement -> Escrow -> Execution -> Settlement -> Reputation -> Memory).
*   **Sprint 9 — SDK:** Developer abstraction layer. Devs think in agents, jobs, and agreements, not contract addresses.

## Phase B — Hardening
*   **Security:** Run Slither, Mythril, Echidna, Medusa, Halmos until clean. Every issue fixed, documented, or accepted.
*   **Test Coverage:** Unit, Integration, Fuzz, Invariant, Scenario.
*   **End-to-End Scenario:** A single, unbroken execution flow proving the entire lifecycle from Identity to Memory without manual intervention.

## Phase C — Protocol Polish
*   **Documentation:** Architecture, ThreatModel, Storage, SDK, Deployment, Examples, Economics, Governance, Audits.
*   **ADR & RFC Freeze:** Architecture becomes stable. No structural rewrites.

## Phase D — Independent Review
*   **Architecture:** Can this protocol evolve?
*   **Security:** Can assets be stolen?
*   **Economics:** Can incentives be manipulated?
*   **Governance:** Can the protocol be captured?

## Phase E — Beta
Deploy. Break. Measure. Fix. Repeat.

## Phase F — Release Candidate
Feature complete. Only bug fixes, gas improvements, and audit findings.

## Phase G — v2.0
Production launch.
