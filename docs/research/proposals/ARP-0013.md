# ARP-0013

# AI Agent Identity Model

Status: Draft

Version: 1.0

Category: Identity

Requires: ARP-0004

---

# Abstract

This document defines the protocol model for artificial intelligence agents participating within the Akmena Protocol.

An AI agent is an independent economic actor capable of entering agreements, receiving payments, building reputation, and interacting with protocol primitives.

Identity establishes ownership.

Identity does not establish trust.
