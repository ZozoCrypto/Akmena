# ARP-0025

# Protocol Upgrade Policy

Status: Draft

Version: 1.0

Category: Governance

---

## Abstract

Protocol evolution must preserve compatibility, simplicity, and security.

---

## Rules

Lower layers change rarely.

Upper layers change frequently.

Breaking changes require new protocol versions.

Financial kernel upgrades require extraordinary justification.

Applications SHALL never dictate protocol architecture.

---

## Conclusion

Evolution without protocol drift.
