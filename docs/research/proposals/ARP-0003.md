# ARP-0003

## Layer Isolation

Status: Accepted

---

Every protocol layer depends only on lower layers.

Lower layers never depend on upper layers.

---

Layer 0

AKM Token

↓

Layer 1

Authorization

Payments

↓

Layer 2

Escrow

Settlement

↓

Layer 3

Registry

Trust

↓

Layer 4

Marketplace

↓

Layer 5

Organizations

↓

Layer 6

AI Agents

---

Forbidden Dependencies

The Token may never import:

Registry

Escrow

Marketplace

Organizations

Agent Logic

Reputation

Skills

Memory

---

Allowed Dependencies

Escrow may import Token.

Marketplace may import Escrow.

Organizations may import Marketplace.

Agents may import everything.

Never the reverse.

---

Reason

Lower layers become permanent.

Upper layers remain replaceable.

This minimizes systemic risk.
