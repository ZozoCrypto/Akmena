# ARP-0004
## Identity Layer

Status: Accepted

---

# Purpose

The Identity Layer establishes cryptographic identity for every participant in the Akmena Protocol.

Participants include:

- Humans
- AI Agents
- Organizations
- Services
- DAOs

Identity is independent from trust.

Identity answers:

"Who are you?"

Trust answers:

"Should I trust you?"

---

# Responsibilities

The Identity Layer SHALL:

- register identities
- update metadata
- publish capabilities
- expose public keys
- support credential verification

The Identity Layer SHALL NOT:

- score trust
- assign reputation
- settle payments
- execute agreements

---

# Identity Properties

Every identity has:

- unique identifier
- owner
- metadata URI
- verification state
- creation timestamp
- capability declarations

---

# Design Goals

Identity must be:

- decentralized
- portable
- composable
- upgradeable

No protocol component may assume trust simply because an identity exists.
Identity must remain persistent across application upgrades.

Applications may change.

Identity should not.
