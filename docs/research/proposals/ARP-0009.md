# ARP-0009
## AI Memory

Status: Accepted

---

# Purpose

Memory allows AI agents to preserve context across interactions.

---

Memory SHALL

be cryptographically anchored

be permission controlled

support selective disclosure

remain portable

---

Memory SHALL NOT

modify balances

modify trust

execute transactions

replace identity

---

Memory is knowledge.

Identity is ownership.

Trust is behavior.
Memory SHALL remain verifiable.

Memory need not remain public.
