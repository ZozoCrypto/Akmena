# APS-300

# Reputation Standard

Version: 1.0

Status: Draft

Category: Trust Layer

Authority: Protocol Standard

Classification: Normative

---

# Purpose

This standard defines reputation as a protocol primitive.

Reputation is accumulated protocol history derived from verifiable participant behavior.

Reputation is descriptive.

It is not authority.

---

# Scope

This standard governs:

* reputation records
* reputation accumulation
* reputation persistence
* reputation portability
* reputation interpretation

---

# Reputation Principles

Reputation SHALL be:

* historical
* observable
* deterministic
* portable
* implementation independent

Reputation SHALL NOT directly grant protocol permissions.

---

# Reputation Sources

Reputation MAY derive from:

* completed agreements
* fulfilled obligations
* successful settlements
* verified attestations
* protocol participation
* governance participation

---

# Normative Requirements

Reputation SHALL reference protocol identities.

Reputation SHALL survive controller rotation.

Reputation SHALL remain independently verifiable.

Reputation SHALL NOT be transferable between identities.

---

# Compliance

Implementations SHALL preserve historical reputation records.

Historical protocol events SHALL remain immutable.

---

# Security Considerations

Reputation systems SHALL resist manipulation.

Reputation SHALL be derived from verifiable protocol events.
