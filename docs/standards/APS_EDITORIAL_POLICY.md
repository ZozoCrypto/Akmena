# APS Editorial Policy

Version: 1.0

Status: Normative

Authority: Standards

---

# Purpose

Defines editorial requirements for all Akmena standards.

---

# Editorial Rules

Every standard SHALL:

Use canonical terminology.

Avoid duplicated definitions.

Reference the glossary.

Reference related standards.

Remain implementation independent.

---

# Consistency

All standards SHALL use identical section ordering.

Formatting SHALL remain consistent.

Terminology SHALL remain consistent.

---

# Freeze Review

Before publication every APS SHALL pass:

* Technical Review
* Editorial Review
* Security Review
* Cross-reference Review
* Traceability Review

Only then may the APS become Frozen.
