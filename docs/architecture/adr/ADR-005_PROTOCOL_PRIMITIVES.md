# ADR-005

# Protocol Primitives

Status: Accepted

Decision Type: Architecture

---

# Decision

Core protocol concepts shall be represented as reusable primitives rather than embedded implementation logic.

Examples include Identity, Escrow, Agreement, Settlement, Memory, and Capability.

---

# Rationale

Reusable primitives enable composability and simplify future protocol evolution.
