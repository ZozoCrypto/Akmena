# ADR-004

# Authorization vs Trust

Status: Accepted

Decision Type: Security

---

# Decision

Authorization and trust are independent protocol concepts.

Authorization determines permission.

Trust influences participant decisions.

Neither implies the other.

---

# Rationale

Separating these concepts reduces privilege escalation and preserves deterministic protocol behavior.

---

# Consequences

Improved security

Reduced ambiguity

Clear responsibility boundaries
