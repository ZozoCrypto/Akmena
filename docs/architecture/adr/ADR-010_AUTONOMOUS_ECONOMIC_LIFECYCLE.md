# ADR-010

# Autonomous Economic Lifecycle

Status: Accepted

Decision Type: Autonomous Economy

---

# Decision

The protocol adopts the Autonomous Economic Lifecycle defined in Book XI as the canonical behavioral model for autonomous participants.

Implementations may differ internally but shall preserve the lifecycle semantics.

# Rationale
