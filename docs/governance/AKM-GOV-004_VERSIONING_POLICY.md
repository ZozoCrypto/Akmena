# AKM-GOV-004

# Akmena Versioning Policy

Version: 1.0

Status: Normative

Authority: Governance

---

# Purpose

This document defines protocol versioning.

---

# Version Format

The protocol SHALL use semantic versioning.

MAJOR.MINOR.PATCH

Example:

1.0.0

---

# Major Version

Major versions introduce protocol-level changes that may affect compatibility.

Examples:

* New protocol primitives
* Constitutional amendments
* Breaking protocol behavior

---

# Minor Version

Minor versions introduce new functionality while preserving compatibility.

Examples:

* New APS documents
* New RFCs
* Additional protocol features

---

# Patch Version

Patch versions correct defects without changing protocol behavior.

Examples:

* Editorial corrections
* Reference implementation fixes
* Clarifications

---

# Frozen Versions

A frozen version SHALL NOT change.

Corrections require publication of a subsequent version.

---

# Compatibility

Every released implementation SHALL declare the protocol version it implements.

---

# Version Authority

Only Governance may approve new protocol versions.

---

# Version References

Every document SHALL identify the protocol version under which it was published.

---

# Amendment

Changes to this policy require Governance approval.
