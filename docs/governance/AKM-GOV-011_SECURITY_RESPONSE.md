---

# Purpose

This document defines how protocol security issues are reported, evaluated, and resolved.

---

# Security Priorities

The protocol prioritizes:

1. User safety
2. Asset integrity
3. Protocol correctness
4. Ecosystem stability
5. Transparency

---

# Vulnerability Reporting

Security issues SHOULD be reported privately until mitigation is available.

---

# Severity Levels

Critical

High

Medium

Low

Informational

---

# Response Process

Report

↓

Verification

↓

Risk Assessment

↓

Mitigation

↓

Review

↓

Disclosure

↓

Release

---

# Emergency Authority

Emergency fixes MAY be issued before public disclosure when required to protect protocol participants.

Emergency actions SHALL be documented afterward.

---

# Amendment

Changes require Governance approval.
