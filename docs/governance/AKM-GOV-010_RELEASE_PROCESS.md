# AKM-GOV-010

# Akmena Release Process

Document ID: AKM-GOV-010

Version: 1.0

Status: Normative

Authority: Governance

---

# Purpose

This document defines the official process for releasing new protocol versions.

---

# Release Requirements

Every protocol release SHALL satisfy:

* Governance approved
* APS updated
* ADRs complete
* RFCs updated
* Specification updated
* Reference implementation complete
* Tests passing
* Security review completed

---

# Release Types

Major

Introduces breaking protocol behavior.

Minor

Introduces backward-compatible protocol features.

Patch

Corrects defects without altering protocol behavior.

---

# Release Artifacts

Every release SHALL publish:

* Protocol Specification
* APS Index
* ADR Index
* RFC Index
* Reference Implementation
* Test Results
* Release Notes
* Version Manifest

---

# Frozen Releases

Published releases SHALL become immutable reference versions.

---

# Amendment

Changes require Governance approval.
