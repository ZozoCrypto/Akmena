# AKM-GOV-012

# Reference Implementation Policy

Document ID: AKM-GOV-012

Version: 1.0

Status: Normative

Authority: Governance

---

# Purpose

Defines the role of official reference implementations.

---

# Reference Implementation

Reference implementations demonstrate protocol compliance.

They SHALL NOT redefine protocol behavior.

---

# Requirements

Reference implementations SHALL:

* Implement frozen specifications
* Pass conformance tests
* Publish supported protocol version
* Maintain complete documentation

---

# Alternative Implementations

Independent implementations are encouraged provided they conform to the Specification.

---

# Compliance

Conformance SHALL be measured against protocol behavior, not implementation details.
