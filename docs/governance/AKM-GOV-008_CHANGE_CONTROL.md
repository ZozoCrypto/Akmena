# Akmena Change Control

Document ID: AKM-GOV-008

Version: 1.0

Status: Normative

Authority: Governance

---

# Purpose

This document defines how protocol changes are proposed, reviewed, approved, and adopted.

---

# Change Sources

Changes may originate from:

* Research
* Security findings
* Community proposals
* Implementation experience

---

# Change Process

Every protocol change SHALL follow:

Research

↓

ARP

↓

ADR

↓

APS

↓

RFC

↓

Specification

↓

Implementation

↓

Verification

↓

Audit

↓

Release

---

# Emergency Changes

Emergency security fixes SHALL still be documented after implementation.

Emergency status SHALL NOT permanently bypass governance.

---

# Breaking Changes

Breaking changes require a Major protocol version.

---

# Editorial Changes

Editorial corrections MAY be issued without changing protocol behavior.
