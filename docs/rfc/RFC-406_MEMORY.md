# Purpose

Defines persistent protocol Memory.

---

# Canonical Definition

Memory records completed protocol interactions for future reference.

Memory records observations.

Memory does not perform learning.

Learning belongs to Participants.

---

# Object Invariants

* Memory SHALL remain append-only.
* Memory SHALL preserve historical integrity.
* Memory SHALL reference completed events.
* Memory SHALL remain deterministic.

---
