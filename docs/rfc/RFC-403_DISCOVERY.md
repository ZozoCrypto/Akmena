# Purpose

Discovery enables Participants to locate protocol resources.

---

# Canonical Definition

Discovery provides standardized mechanisms for locating protocol Participants, Services, Skills, Organizations, and Agreements.

Discovery does not evaluate quality.

Discovery identifies availability.

---

# Object Invariants

* Discovery SHALL remain deterministic.
* Discovery SHALL NOT modify protocol state.
* Discovery SHALL remain implementation independent.
