# Purpose

---

# Canonical Definition

A Skill represents a standardized reusable competency available to Participants.

Skills describe competence.

Services utilize Skills.

# Object Invariants

* Skills SHALL remain reusable.
* Skills SHALL remain independently referenceable.
* Skills SHALL remain implementation independent.
